# VILQA backend

- `src/` — проверяемые исходники функций. Из них генерируются повторяющиеся Code-узлы n8n.
- `workflows/` — актуальные экспорты шести рабочих workflow без execution data и секретов credentials.
- `migrations/20261030_fiber_delivery.sql` — текущая миграция очереди доставки.
- `migrations/legacy/` — исторические SQL, сохранены для чтения. Не запускайте всю папку по алфавиту: она содержит разные версии функций.
- `tests/` — поддерживаемые тесты. SQL-тест доставки выполняется транзакционно и откатывает фикстуры.
- `tools/` — генерация и запуск тестов.
- `docs/` — порядок выпуска и восстановления.

## Проверки

Из корня репозитория: `npm --prefix backend test`.

Для браузерного сценария: `npm --prefix backend install`, затем `npm --prefix backend run test:ui`. На текущем Windows используется установленный Edge. Запись порции проверяется вместе с потерей ответа и повтором того же request_id: создаётся ровно одна запись.

Для проверки Safari: `node backend/node_modules/playwright/cli.js install webkit`, затем `npm --prefix backend run test:webkit`. Геометрия панели проверяется на ширинах 320, 390, 440 и 560 CSS px; 440 CSS px соответствует портретному viewport iPhone 16 Pro Max. WebKit на компьютере воспроизводит CSS-движок, но не заменяет проверку на физическом iPhone.

Изменяйте общие функции в `src/`, затем выполняйте `npm --prefix backend run generate`. Проверка `check:generated` выявляет расхождение модулей и workflow. Тесты больше не используют старые draft JSON из временных папок.

## Доставка клетчатки

`fiber_queue_notice` сохраняет уведомление и выдаёт аренду единственному отправителю. `fiber_finish_notice` отмечает доставку только после message_id от Telegram. Явные временные отказы могут повторяться; при неизвестном исходе сообщение не пересылается вслепую и ошибка попадает в общий обработчик. Доставка и расчёт — разные состояния. Правки/удаления еды по-прежнему выполняются без уведомлений.

## Границы резервной копии

Рабочие данные, execution logs, старые snapshots и архивы maintenance хранятся вне Git. Для развёртывания на пустой сервер нужен полный PostgreSQL/n8n backup с encryption key; одного workflow JSON недостаточно. Локальный бэкап перед этим выпуском содержит файлы, Git bundle, функции и данные приложения; он не является образом сервера.
