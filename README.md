# VILQA

`index.html` — регистрация; `diary/` — Telegram Mini App; `backend/` — workflow n8n, исходники, SQL и поддерживаемые тесты.

Проверка: `npm --prefix backend test`. Браузерные сценарии: `npm --prefix backend run test:ui`.

Рабочие данные и резервные копии находятся отдельно от репозитория. См. [backend/README.md](backend/README.md) перед изменением workflow и миграций.
